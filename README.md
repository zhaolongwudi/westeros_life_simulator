# 🐺 维斯特洛人生模拟器

> ### *凛冬不是惩罚。它只是这个世界的季节之一。*

七大王国照常运转，泰温·兰尼斯特照常微笑，长城以北的寒意照常蔓延。
而你——**不是**被预言选中的王子，没有谁欠你一个伟大的命运。
**你只是在维斯特洛出生的一个人。**

---

## 🔥 这不是一款普通的游戏

没有天选之人，没有命运剧本。这个世界不会围着你的名字打转：

- 你可以在乱世里**白手起家**，也可以在巨人的阴影下**安然度日**
- 可以握着剑**一路向北**，也可以握着账本在**君临站稳脚跟**
- 历史照常运转，四季照常轮转——**你是否参与，世界都无妨**
- 但只要你愿意，**这里的人生，由你亲手书写**

---

## 🎭 你将扮演谁

开局时，从 **10 种身份** 中选择其一，每一种都通向截然不同的人生：

| 身份 | 你的人生剧本 |
|------|------|
| 🏰 贵族 | 生来不凡。家族、领地、继承权，以及随之而来的背叛与责任 |
| 🧑‍🌾 平民 | 一无所有，但自由。你可以选择在任何地方成为任何人 |
| ⚔️ 士兵 | 刀口舔血。功勋、军饷，或者一场无名氏的战死 |
| 🏪 商人 | 金币即权力。商路、集市、铁金库的门槛等你跨过 |
| ⛪ 神职人员 | 信仰是最锋利的武器。旧神、七神，或你自己的信条 |
| 📚 学者 | 知识即力量。学城、古卷、被遗忘的历史 |
| 🗺️ 冒险者 | 世界的每个角落都在向你招手 |
| 🗡️ 刺客 | 阴影中的交易，见血封喉 |
| 🎓 学士 | 渡鸦、锁链与誓言。真相有时比剑更致命 |
| 🌲 野人 | 长城之外，自由民的血性 |

还可以从 **27 个家族** 中选择出身——史塔克、兰尼斯特、坦格利安……或者干脆当个自由民，并决定你的出生地点、时代与季节。

> 🌰 一句简单的话，就是一段传奇的起点：
> `篡夺者战争后，临冬城，史塔克家族，春天。`

## 🌍 这个世界有多大

- 🏰 **27 个家族**——族语、规模、影响力、军队、秘密、对外关系，恩怨情仇交织成网
- 🗺️ **68 个地点**——北境雪原、君临红堡、长城绝境、铁群岛、多恩、厄索斯……跨越九大区域
- 🧑‍🤝‍🧑 **36 位 NPC**——有名有姓、有性格、有立场，他们有自己的生活，有的会给你写信
- ⚙️ **74 个世界系统**——封建、继承、婚姻、法律、守夜人、学城、教会、铁金库、无面者、龙……你接触到的每一个系统都在影响世界与你
- 📜 **60 个事件**——政治阴谋、家族恩怨、战争阴云、宗教纷争、神秘异象，命运随时敲门

---

## 🎮 你可以做什么

- ⚔️ **训练**（sword / archery / riding / speech / alchemy）——成为传奇，或死在半路上
- 💰 **工作 / 贸易 / 狩猎**——按身份赚取金币，商人有商人的路子，士兵有士兵的活计
- 🧭 **旅行 / 探索**——在 68 个地点间穿行，探索可能发现财宝，也可能撞上强盗
- 🦅 **信件**——NPC 会主动给你写信，回信可以增进关系
- 💬 **互动**——「在场」查看身边人物，「互动 `<名字>`」深度交谈（好感越高内容越深），「示好 `<名字>`」送礼拉近关系，挚友可结盟
- 📖 **事件**——可触发的事件会随你的处境浮现，选择决定因果
- 📅 **过月 / 时间流逝**——四季轮转，凛冬会让生活成本上升；系统在暗中演进，世界不会原地等你
- ✨ **AI 行动模式**——把你想做的事直接说出来，AI 生成叙事与选项，选择后真实改变你的状态

---

## 🤖 AI 行动模式

输入一句话，世界就会回应你：

```
▶ 尝试说服北境领主支持我争夺继承权
▶ 在君临的酒馆打听最近的流言
▶ 招募一队佣兵去长城猎杀野人
```

AI 会基于你当前的**状态、处境、在场 NPC、可触发事件**，生成一段至少 200 字的叙事，并给出 2~4 个选择。你的选择会**真实地**改写：

- 💰 **金币与声望**——穷困潦倒还是富甲一方，默默无闻还是名动天下
- 🗡️ **技能与属性**——剑术、骑术、口才、力量、智慧……每一次磨砺都算数
- 🤝 **NPC 好感**——赢得提利昂的青睐，或让瑟曦记恨你一辈子
- 🚩 **世界状态**——你立下的誓言、背负的诅咒、获得的头衔，都会在世界中留下印记

然后时间继续向前，四季轮转，**世界回应你的每一个选择**。

> 🌊 你做的每一个选择，都会成为这个世界的一部分。

## 💭 设计哲学

- **世界不围绕玩家存在**——历史照常运转，你是否参与都无妨
- **玩家可以是任何人**——没有唯一主角，你的身份由你定义
- **历史不会停止**——每一回合，世界都在向前
- **家族不是职业**——出身只是起点，不是剧本
- **封建权力结构复杂**——荣誉、忠诚、野心与背叛，从来不是简单的对错
