**关键设计决定（与卡片原文有出入，记录在案）**

1. **只做了 2 个，不是 3 个。** 卡片点名「守夜人誓言 / 铁金库债务 / 学城委托」，但**铁金库取证后判定不能挂效果**：
   - 全库无持久化债务状态。`event_iron_bank_debt`（`event_data.dart:1130`）/ `event_iron_bank_crisis`（:291）的 `gold: -500` 只是「选择偿还」这个**动作本身**的即时扣款，没有任何地方记录「玩家欠着 500 金」；

3. **复用 `applyEffects` 而非手写 setter。** 效果键合法集、边界钳制（gold 下限 0 / 生存值 0~100 / 好感度 ±100）、五类幽灵键守卫已全部实装在那儿；另起一套就是重演「两条 applyEffects 漂移」（batch10-90 / 10-95 的老教训）。副带好处：无效键会被拒收进 `lastRejectedEffectKeys`，且结算文本里**不宣称结算成功**（`deltas` 为空则不输出，只在有拒收键时给告警行）。
