> S3-2 新增。此前项目没有物品百科，`items.json` 的 33 个物品里有 28 个
> 在任何文档中都查不到（由 `python3 scripts/check_docs_sync.py` 的名称
> 覆盖对账抓出）。物品是背包、贸易、事件效果（`inventory.<itemId>`）与
> AI 叙事的公共输入，缺一本可查的表意味着内容作者无从知道有哪些物品可用。

## 一、字段说明

物品模型是 `lib/data/item_data.dart` 的 `Item`（**目前没有 `fromJson`**，
这是 S4-4「JSON 外置」的前置条件之一）。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `item_` 前缀 |
| `name` | string | 物品名 |
| `category` | enum | `consumable` 消耗品 / `weapon` 武器 / `armor` 护甲 / `material` 材料 / `treasure` 珍宝 / `relic` 圣物 / `document` 文书 / `mount` 坐骑 |
| `value` | int | 金币基准价（现状 1~800） |
| `description` | string | 描述 |
| `stackable` | bool | 可堆叠（否则每件占一格背包） |
| `usable` | bool | 可主动使用（触发 `useEffect`） |
| `useEffect` | Map\<string,int\> | 使用效果，键体系同事件效果键（见 `docs/specs/content-schema.md` §4） |
| `requiresSkill` | string | 使用所需技能，空串 = 无要求 |

**在事件里发放/消耗物品**用扁平点号键 `inventory.<itemId>`，例如
`{'inventory.item_wine': 1}`。作为**选项门槛**用 `hasItem.<itemId>`，
例如 `{'hasItem.item_dagger': 1}`（语义是"持有数量 ≥ 值"）。
