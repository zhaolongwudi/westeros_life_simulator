# 01 · 世界百科

## 一、地理总览

### 维斯特洛（Westeros）
南北狭长大陆，面积约 100 万平方公里。北端长城，南端多恩沙漠。

### 厄索斯（Essos）
东方大陆，面积约为维斯特洛 3 倍。包含自由贸易城邦、多斯拉克海、奴隶湾、夷地、阴影之地。

### 盛夏群岛（Summer Isles）
维斯特洛东南方群岛，气候温暖，盛产香料与丝绸。

### 索斯罗斯（Sossath）
南方未知大陆，仅少数探险家抵达。

## 三、季节系统

维斯特洛季节无固定长度：
- 春天：1 个月 ~ 数年
- 夏天：1 个月 ~ 数年
- 秋天：1 个月 ~ 数年
- 冬天：1 个月 ~ 数十年

**凛冬**：持续多年的严冬，伴随异鬼南下、野人迁徙、粮食短缺。

## 十、世界演化规则

### 月度世界动态

每月结算：
- 王国：国王动态、御前会议、叛乱
- 战争：战线推进、战役结果
- 家族：兴衰、联姻、继承
- 教会：总主教更替、宗教事件
- 学城：新理论、新发现
- 经济：物价波动、贸易路线
- 季节：季节变化、天气异常
- 长城：守夜人动态、异鬼报告
- 异鬼：南下、集结、袭击
- 龙：出现、孵化、飞行
- 多斯拉克：迁徙、掠夺、卡奥更替
- 自由贸易城邦：战争、贸易、政变
- 玩家地区：本地事件、传闻

### 世界不围绕玩家

- 玩家不参与，世界照样发展
- 玩家可能一辈子不见龙或异鬼
- 传奇人物有自己的计划
- 历史不会因玩家而改变

## 十二、世界规则保护

### 防止过度热闹

禁止：
- 每个月都有龙
- 每个月都有异鬼
- 每个月都有神器
- 每个月都有王国战争

维斯特洛必须拥有大量普通生活。

### 防止主角光环

玩家没有：
- 默认传奇血统
- 默认神明眷顾
- 默认神器
- 默认美女环绕
- 默认龙蛋

除非通过世界中的行动获得。

### 防止数值刷子

禁止：
- 站在森林砍 1000 只野猪升级剑术
- 重复低难度动作成长收益迅速下降
- 真正成长来自新环境、新问题、新理解

### 防止经济漏洞

禁止：
- 无成本炼金
- 无限金币
- 无限复制瓦雷利亚钢
- 无限刷龙蛋
- 无限刷商人
- 无限刷任务奖励

## 十五、终极原则

### 自由

玩家可以尝试任何合理行为。

### 家族

血统、族语、仇恨与荣誉真实存在。

### 政治

王权、贵族、教会、商人彼此制衡。

### 宗教

七神、旧神、淹神、光之王、千面之神并存。

### 魔法

低魔、稀有、危险、不可靠。

### 战争

家族战争、王位战争、宗教战争、入侵战争、独立战争。

### 经济

农业、手工业、商业、矿业、渔业、羊毛贸易、葡萄酒贸易、奴隶贸易。

### 历史

世界拥有数千年历史，历史是现实力量。

### 因果

玩家行为影响今天、明天、十年后。

### 死亡

死亡默认真实，NPC 不会因玩家喜欢而复活。

### 继承

玩家死亡后可切换子女或继承人，下一代拥有独立人格。

### 多世代

可以从祖父到孙辈连续玩，形成持续数百年的家族史。

### 历史记忆

如果玩家成为传奇人物，后世可能记载、神化、歌颂、批判、忘记。

### 世界史书

玩家甚至可能在游戏后期阅读一本记录自己时代的历史书。
