## 四、玩法组合

### 1. 农民 → 商人 → 骑士 → 领主

**路径**：
- 农民：经营农场，积累财富
- 商人：开商铺，建立商业帝国
- 骑士：参加比武，追求荣誉
- 领主：管理领地，维护家族

### 2. 贵族 → 破产 → 雇佣兵

**路径**：
- 贵族：管理领地，维护家族
- 破产：家族衰落，失去领地
- 雇佣兵：寻找雇佣，追求荣誉

### 3. 学士 → 顾问 → 大学士

**路径**：
- 学士：学习知识，管理乌鸦
- 顾问：服务于领主，提供建议
- 大学士：成为学城领袖

### 4. 奴隶 → 自由人 → 商人

**路径**：
- 奴隶：被奴役，积累财富
- 自由人：获得自由，开始新生活
- 商人：开商铺，建立商业帝国

### 5. 海盗 → 领主 → 国王

**路径**：
- 海盗：袭击商船，积累财富
- 领主：成为领主，管理领地
- 国王：推翻旧王国，成为国王

## 五、玩法限制

### 1. 防止主角光环

玩家没有：
- 默认传奇血统
- 默认神明眷顾
- 默认神器
- 默认美女环绕
- 默认龙蛋

除非通过世界中的行动获得。

### 2. 防止数值刷子

禁止：
- 站在森林砍 1000 只野猪升级剑术
- 重复低难度动作成长收益迅速下降
- 真正成长来自新环境、新问题、新理解

### 3. 防止经济漏洞

禁止：
- 无成本炼金
- 无限金币
- 无限复制瓦雷利亚钢
- 无限刷龙蛋
- 无限刷商人
- 无限刷任务奖励

### 4. 防止过度热闹

禁止：
- 每个月都有龙
- 每个月都有异鬼
- 每个月都有神器
- 每个月都有王国战争

维斯特洛必须拥有大量普通生活。

### 5. 防止剧透隐藏真相

玩家不能自动知道：
- 哪个 NPC 是传奇人物
- 国王什么时候会死
- 哪条商路会发财
- 谁在密谋背叛

必须调查、推理、社交、观察。

### 6. 防止强行复活 NPC

NPC 可能：
- 病死
- 战死
- 被刺杀
- 老死
- 意外死亡
- 被处死
- 被毒死
- 被龙烧死

不会因为玩家喜欢就强行复活。

### 7. 防止无限刷

禁止：
- 无限刷钱
- 无限刷装备
- 无限刷好感
- 无限刷新事件
- 无限刷神器
- 无限刷龙

世界资源必须有成本、有产出、有消耗。

## 七、玩法惩罚

### 1. 失败系统

玩家可能：
- 战斗失败
- 生意失败
- 婚姻失败
- 政治失败
- 冒险失败
- 被逐出家族
- 被教会审判
- 家族衰落
- 被流放

失败不会自动结束人生。

### 2. 死亡系统

玩家可能：
- 战死
- 被刺杀
- 被处死
- 被毒死
- 被龙烧死
- 被异鬼杀死
- 病死
- 老死
- 意外死亡

死亡默认真实。

### 3. 继承系统

玩家死亡后可以切换子女或继承人。继承：
- 家产
- 家族
- 声誉
- 人际关系
- 部分知识
- 仇恨

但下一代拥有独立人格。

## 十、玩法终极原则

### 1. 自由

玩家可以尝试任何合理行为。

### 2. 家族

血统、族语、仇恨与荣誉真实存在。

### 3. 政治

王权、贵族、教会、商人彼此制衡。

### 4. 宗教

七神、旧神、淹神、光之王、千面之神并存。

### 5. 魔法

低魔、稀有、危险、不可靠。

### 6. 战争

家族战争、王位战争、宗教战争、入侵战争、独立战争。

### 7. 经济

农业、手工业、商业、矿业、渔业、羊毛贸易、葡萄酒贸易、奴隶贸易。

### 8. 历史

世界拥有数千年历史，历史是现实力量。

### 9. 因果

玩家行为影响今天、明天、十年后。

### 10. 死亡

死亡默认真实，NPC 不会因玩家喜欢而复活。

### 11. 继承

玩家死亡后可切换子女或继承人，下一代拥有独立人格。

### 12. 多世代

可以从祖父到孙辈连续玩，形成持续数百年的家族史。

### 13. 历史记忆

如果玩家成为传奇人物，后世可能记载、神化、歌颂、批判、忘记。

### 14. 世界史书

玩家甚至可能在游戏后期阅读一本记录自己时代的历史书。

## 十一、玩法开始

### 1. 开始游戏

玩家输入【开始】后，生成初始角色：
- 随机家族
- 随机身份
- 随机地点
- 随机时间
- 随机季节

然后进入月度循环。

### 2. 月度循环

每月结算：
- 世界动态
- 玩家状态
- 叙事
- 选项
- 存档提示

### 3. 结束游戏

玩家死亡后，可以：
- 切换子女或继承人
- 继续玩
- 结束游戏
